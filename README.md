## 📌 Project Overview

Student Marks Analyzer is a Python project built using **NumPy** that analyzes student performance through a clean, modular, and interactive application.

The project started as a **Command Line Interface (CLI)** application and has now evolved into a **professional desktop application** using **CustomTkinter**.

The application features **Role-Based Authentication**, allowing **Students** and **Administrators** to securely access different functionalities based on their permissions.

It performs detailed student performance analysis by calculating statistics, rankings, grades, subject-wise insights, class analytics, and individual report cards through both the CLI and a modern graphical user interface.

This project is part of my Machine Learning learning journey, where I am mastering Python libraries by building real-world projects while following clean coding practices and modular software architecture.

# ⚙ How It Works

## CLI Version

- Run `main.py`
- Login as Student or Admin
- Access all CLI analysis features

---

## GUI Version

- Run `gui.py`
- Login as Student or Admin
- Access a modern dashboard
- Navigate through interactive pages
- View reports and statistics

The GUI communicates with **analyzer_engine.py**, which performs all calculations and returns processed data for display.
